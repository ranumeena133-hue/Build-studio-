── 0. SABSE AASAAN TARIKA (ek baar setup, phir sirf "getfiles") ──
EK BAAR ye chalao:
curl -sL "https://raw.githubusercontent.com/ranumeena133-hue/Build-studio-/arena/01a07dfe-build-studio/termux-setup.sh" | bash
Uske baad HAMESHA bas ye type karo:
getfiles

── 1. Saari files ek ZIP me ────────────────────────
curl -L "https://raw.githubusercontent.com/ranumeena133-hue/Build-studio-/arena/01a07dfe-build-studio/build-studio-files.zip" -o /sdcard/Download/build-studio-files.zip

── 2. ZIP extract karna ho to ──────────────────────
pkg install -y unzip
unzip /sdcard/Download/build-studio-files.zip -d /sdcard/Download/build-studio/

── 3. Koi ek file (example: demo.md) ───────────────
curl -L "https://raw.githubusercontent.com/ranumeena133-hue/Build-studio-/arena/01a07dfe-build-studio/storage/demo.md" -o /sdcard/Download/demo.md

── 4. PHONE SE UPLOAD — 2 tarike 📤 ────────────────
TARIKA A (Termux se, best):
  Pehli baar setup:
    pkg install -y gh
    gh auth login        (browser khulega, login karo)
  Phir hamesha:
    sendfile merifile.pdf
    (subfolder me bhejna ho: sendfile merifile.pdf pics)
  Uske baad chat me bolo "pull karo" — done!

TARIKA B (phone browser se):
  https://github.com/ranumeena133-hue/Build-studio-/upload/arena/01a07dfe-build-studio/storage
